# 🐍 Aprendendo Python

Bem-vindo ao meu repositório de estudos de **Python**!

Este projeto foi criado para registrar toda a minha evolução na linguagem Python, desde os fundamentos até o desenvolvimento de aplicações com **Machine Learning**, **Inteligência Artificial** e **Visão Computacional**.

---

## 🎯 Objetivo

Meu objetivo é aprender Python de forma sólida, aplicando cada conceito na prática, até desenvolver um sistema de **Visão Computacional** capaz de identificar motociclistas sem capacete utilizando Inteligência Artificial.

## 💻 Como executar

Clone este repositório:

```bash
git clone https://github.com/RubensDutra/aprendendo_python.git
```

Acesse a pasta:

```bash
cd aprendendo_python
```

Ative o ambiente virtual:

### Windows

```bash
.\.venv\Scripts\activate
```

Execute um arquivo Python:

```bash
python aulas/aula01_variaveis.py
```
